# Vastra-Lane-fashion-website
A responsive fashion and clothing website showcasing clothing collections, product categories, seasonal trends, and a modern shopping interface built using HTML, CSS, and basic JavaScript.
### ✨ Style, Simply Yours.

## 📌 About
Vastra Lane is a modern fashion website designed using HTML, CSS, and basic JavaScript. It showcases clothing, ethnic wear, footwear, and accessories with a minimal brown and cream theme.

## 🎯 Objective
To create a simple, responsive, and interactive fashion website using basic web development technologies.

## ✨ Features
- 🏠 Home page with featured products
- 🛍️ Collection page with 16 product cards
- ℹ️ About page with contact section
- 👜 Interactive Add to Bag counter
- 📱 Responsive design for mobile and desktop
- 🤎 Minimal editorial design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Files
- `index.html` – Home page
- `collection.html` – Collection page
- `about.html` – About page
- `style.css` – Website styling
- `script.js` – Interactive features
- `README.md` – Project documentation
